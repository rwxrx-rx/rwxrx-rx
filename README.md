## 👨‍💻 About Me

I work on the parts of Android that most people never see — kernel trees, root frameworks, and the build systems behind them. Most of my time goes into a custom **Linux 4.14 (non-GKI)** kernel for the **MediaTek MT6833** (Poco M3 Pro 5G / Redmi Note 10 5G, codename `camellia`), along with the CI/CD pipeline that builds it.

- 🔧 **Kernel Development:** Maintaining a non-GKI kernel tree with scheduler tuning and LTO optimization.
- 🛡️ **Root Integrations:** Integrating KernelSU and its forks (Next, SukiSU Ultra, xxKSU, ReSukiSU) with SuSFS.
- ☁️ **Automation:** Moving kernel & manager APK builds fully onto GitHub Actions (headless CI/CD).
- 📦 **Recovery Image:** Occasional recovery builder work (TWRP / OrangeFox).
