### 🛠️ What I Do (When Not Fixing Bootloops)

- 🐧 **Linux Kernel Trees:** Porting & maintaining custom 4.14 kernels for MediaTek MT6833 (`camellia`).
- 🛡️ **Kernel Root & Anti-Detect:** Hacking KernelSU multi-forks, SuSFS 4.14, and Baseband-Guard (BBG).
- ⚙️ **Low-Level Tooling:** C/C++, Rust `lpud` cross-compilation, and Bash scripts written at 3 AM.
- 🤖 **Automated Workflows:** Headless GitHub Actions CI/CD pipelines to build kernels so my laptop doesn't explode.
